# File-Renamer

- Since i have alot of downloaded shows and i noticed i rename them all the same way,I decided to create a simple streamlit application to do the renaming for me rather than do it manually

# Stack

- uv for env management
- streamlit for frontend
- python for file handling and rename logic

# Before You Begin

- run uv sync to get all dependencies used in the env

# Running the app

- streamlit run ./main.py


# NB

- this only works on files saved as getvid repeatedly e.g getvid,getvid(1)....getvid(10) etc. If you have a use for this then by all means go ahead and use it for yourself,I just made this to simplify a task I have grown tired of lol
